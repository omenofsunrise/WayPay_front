# Excel-конструктор: решения первой версии

## Формулы и сетка

Используется `@fortune-sheet/react` 1.0.4 и `@fortune-sheet/core` 1.0.4.
Пакеты распространяются под MIT и поддерживают React 18.2 и новее, поэтому
подходят для закрытого WayPay на React 19. HyperFormula не выбран: GPL-3.0
требует открывать производный продукт либо покупать коммерческую лицензию.

## Показатели

Первая версия содержит:

- доход по платежам;
- сумму полученных платежей;
- капитал;
- баланс;
- реинвестированную сумму;
- выплаты инвесторам;
- долю инвестора в капитале.

Значения рассчитывает сервер. Клиент хранит формулы таблицы и привязки ячеек,
но не копирует финансовые формулы. Для существующих расчётов сервер использует
`CalculatorService`; доход рассчитывается по той же формуле, что и в
`PaymentService`.

## Доступ

- Автор может читать, изменять и удалять свою таблицу.
- Автор может сделать таблицу общей для компании.
- Другие сотрудники компании видят общую таблицу только для чтения.
- Таблицы другой компании недоступны.
- `FORBID_TOTAL_INCOME` запрещает выдачу дохода и убирает его из каталога.
- Инвесторские показатели доступны только администраторам, директорам и
  суперадминам.

## Ограничения

- Максимальный размер сохраняемого документа — 1 МБ JSON.
- Показатели ограничены 120 запросами в минуту на сотрудника.
- Привязанные к показателям ячейки нельзя редактировать вручную, пока привязка
  не удалена.
- Серверные показатели обновляются по команде пользователя; формулы зависимых
  ячеек пересчитывает FortuneSheet.

## Развёртывание

Модель `calc_sheets` добавлена без ручной миграции согласно правилам проекта.
Перед выкладкой стандартную EF-миграцию следует сгенерировать из модели и
применить обычным процессом WayPay.
